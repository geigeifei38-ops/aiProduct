## 1. 系统概述

### 1.1 业务目标

读取团队腾讯在线智能表格（周报原始记录表），按人员过滤出**所选周（周一~周五）**的工作内容，依据岗位模板（开发/测试/运维/产品项目管理）自动分类整理，输出标准化的**「本周完成」「下周计划」**两段式周报，支持一键复制，直接粘贴到公司周报系统。

### 1.2 核心功能

| 功能 | 说明 |
|---|---|
| 数据获取 | 四层架构：内置快照 → 本地数据代理（推荐）→ 公共CORS代理（兜底）→ 手动粘贴 |
| 人员过滤 | 姓名精确/包含匹配，支持多人协作记录（如"陈泽彬、陈思曦"）拆分匹配 |
| 周期过滤 | 周一~周五为统计周期，←/→逐周切换、"回到本周"、无数据周一键跳转最近有数据周 |
| 岗位模板 | 4套模板关键词正则自动分类，空分类输出"无"，保持模板条目编号完整 |
| 结果输出 | 本周完成/下周计划双卡片 + 各自独立一键复制（Clipboard API + execCommand降级） |
| 岗位建议 | 按人员当周工作类型（运维/需求/材料等）多数投票自动建议岗位，可手动覆盖 |
| 数据预览 | 折叠表格展示逐条明细（用途/项目/类型/内容/进度/时间），便于核对 |

### 1.3 数据源

- 文档：`https://docs.qq.com/smartsheet/DTkpuTWp3eXJnYm5M?tab=70hIWb`（"我们的项目"）
- 分表（5个）：政企APP（82条）、AI智家助手（45条）、AI政企助手（7条）、数字员工（59条）、其他项目（5条）
- 人员：何健辉、陈思曦、陈泽彬、黄智彬、林志桓、吕守淼（含多人协作记录）

## 4. 数据获取层设计

### 4.1 腾讯文档接口原理（关键约束）

**接口**：`GET https://docs.qq.com/dop-api/opendoc?id={docId}&tab={tabId}&normal=1&outformat=1&noEscape=1`

**认证三要素**（实测结论，缺一即401）：

1. **Cookie**：必须先 GET 对应 smartsheet 页面地址种下 Cookie（`TOK` / `tgw_l7_route` / `traceid` 等）
2. **Referer 头**：携带文档页面地址
3. **无 Origin 头**：⚠️ 浏览器 fetch 跨域请求**必然携带 Origin 头**→腾讯直接返回401（"this url does not allow access from"）

> 结论：**纯前端无法直连腾讯文档接口**；"手动提供Cookie"也无法解决（Origin头拦截与CORS无响应头是双重限制）。因此设计本地数据代理，由服务端发起请求（urllib天然不带Origin头）。

**响应数据定位**：

```
clientVars
└─ collab_client_vars
   ├─ initialAttributedText.text[0]
   │  ├─ smartsheet   （JSON字符串）
   │  │   └─ [0] 数据块数组
   │  │       ├─ t=3005：表结构块 → c['3']['3'] = {字段ID: {30:字段名, 31:类型}}
   │  │       └─ t=3028：记录块   → c['2']['1'] = {记录ID: {1: {字段ID: 单元格值}}}
   │  └─ workbook     （JSON字符串）→ 分表列表 [{id, name, type}]
   └─ padSubId        （当前tabId）
```

**单元格值编码**（按字段类型）：

| 类型key | 含义 | 编码格式 | 示例 |
|---|---|---|---|
| `1` | 文本 | `[{"1":"text","2":"值"},…]` 富文本段拼接 | 工作内容、负责人、备注 |
| `3` | 布尔 | `true/false` | 是否完成 |
| `4` | 日期 | 毫秒时间戳字符串 | 要求/实际完成时间 |
| `28` | 进度 | 数字（0-100） | 完成进度 |

### 4.2 本地数据代理（`本地数据代理.py`）

| 项 | 设计 |
|---|---|
| 技术栈 | Python 3 标准库（`http.server` + `urllib` + `http.cookiejar`），零依赖 |
| 监听 | `127.0.0.1:8790`（仅本机，可用参数改端口）；`ThreadingHTTPServer` 多线程 |
| `GET /ping` | 健康检查，返回 `ok`（页面用于3秒探测） |
| `GET /qq?url=<encoded>` | 核心接口：执行Cookie流程后请求dop-api，原样返回JSON |
| Cookie会话 | 全局共享 `CookieJar`，首次请求自动种Cookie；失败自动重试一次（重新种Cookie） |
| 安全 | 域名白名单正则：`^https://docs\.qq\.com/(smartsheet/\w+|sheet/\w+|dop-api/opendoc\?)`，防止代理被滥用 |
| CORS | 响应 `Access-Control-Allow-Origin: *`，供 `file://` / `localhost` 页面跨域读取 |

**Cookie流程（fetch_via_dance）**：

```
① GET 文档页面地址（还原自url参数的id/tab）→ 种Cookie
② GET dop-api接口（带Referer、携带Cookie、无Origin）→ 200 + JSON
   失败则重新种Cookie再试一次 → 仍失败返回502 + 错误JSON
```

### 4.3 页面在线获取流程（fetchOnline）

```
解析文档地址（提取docId/tabId）
  → 探测本地代理 /ping（3s超时）
     ✓ 就绪 → 代理通道插入获取链首位
     ✗ 未启动 → 日志提示"双击启动本地代理.command"
  → 按链轮询获取主tab（12s超时/通道）
     成功 → 解析workbook分表列表 → 依次拉取其余4个分表（复用成功通道）
  → 全部合并 → 更新数据源徽章（N表/M条）→ 刷新人员快选
  → 全失败 → 降级提示（建议启动代理/手动粘贴），保留原数据不崩溃
```

### 4.4 手动粘贴解析（parsePasted）

| 环节 | 实现 |
|---|---|
| 分隔符探测 | 优先级：`\t`（腾讯文档/Excel复制）> `\|`（Markdown）> `,，`（CSV）> 2+空格；自动跳过Markdown分隔行 |
| 表头映射 | 8类字段别名正则（见下表），未识别内容列时回退"平均文本最长列" |
| 值解析 | 日期：`2026-10-10`/`10.10`/`10月10日`/13位毫秒/10位秒；进度：`100`/`100%`/`0.8`(自动×100)；完成：`是/否/true/false/已完成` |
| CSV引号 | 简化状态机处理双引号包裹 |

**表头别名映射表（COL_ALIAS）**：

| 规范字段 | 匹配正则 |
|---|---|
| type（类型） | `智能表列\|类型\|分类\|类别\|工作类型\|板块` |
| content（工作内容） | `工作内容\|内容\|事项\|工作事项\|任务\|描述\|详情\|工作` |
| owner（负责人） | `负责人\|姓名\|人员\|员工\|执行人\|担当\|成员` |
| note（备注） | `备注\|说明` |
| progress（完成进度） | `完成进度\|进度\|完成度\|百分比` |
| due（要求完成时间） | `要求完成\|计划完成\|预计完成\|截止\|预期` |
| actual（实际完成时间） | `实际完成\|实际进度\|完成时间` |
| finished（是否完成） | `是否完成\|是否已完成\|状态` |

### 4.5 内置快照

页面内嵌 `const SNAPSHOT = {...}`（18KB），由服务端按4.1配方抓取全部5个分表后注入：

```json
{
  "snapshot_time": "2026-10-10 14:28",
  "sheets": [
    { "name": "政企APP",
      "rows": [ { "t":"运维", "c":"码厅运维问题排查", "n":"备注", "o":"陈思曦",
                  "p":100, "f":true, "d":1782662400000, "a":1782662400000 } ] }
  ]
}
```

紧凑键：`t`类型 / `c`内容 / `n`备注 / `o`负责人 / `p`进度 / `f`是否完成 / `d`要求完成 / `a`实际完成（时间为毫秒时间戳，空值省略）。

**快照刷新方式**：按4.1配方（python urllib CookieJar逐tab抓取）重新生成JSON，替换HTML中 `const SNAPSHOT = {...}` 即可。

## 5. 业务逻辑层设计

### 5.1 统一数据模型（canonRow）

所有数据源（快照/在线/手动）统一规范化为：

```javascript
{ type, content, note, owner, progress, finished, due, actual }
//  progress: number|null (0-100)   finished: true|false|null
//  due/actual: 毫秒时间戳|null
```

### 5.2 周期计算

- 周一锚点：`mondayOf(d) = d - ((d.getDay()+6)%7)` 天，置零时分秒
- 周内索引：`dayIdx = Math.floor((ts - 周一) / 86400000)`；`0~4` 即周一~周五（floor兼容文本日期解析产生的+8h偏移）
- 周标签：本周/上周/下周/下上周相对标识 + `M.DD ~ M.DD` 区间

### 5.3 人员匹配

- 负责人字段按 `、，,/;；空格` 拆分为多人（如"陈泽彬、陈思曦"）
- 匹配规则：任一分段与输入姓名 **相等或互相包含**（容错）

### 5.4 本周完成 / 下周计划判定（核心规则）

```
完成态 isDone = finished===true || progress>=100

本周完成（done）：实际完成时间 dayIdx ∈ [0,4]
    · isDone        → 输出原文（可附备注）
    · 未完成        → 追加"（进度xx%）"或"（进行中）"
    · 多分表去重：按 分表名+内容 去重；内容不含项目名时加【项目名】前缀

下周计划（plan）：
    · 下周到期未完成：due dayIdx ∈ [7,11] 且 !isDone → "（计划M.DD完成）"
    · 本周结转：实际完成时间在本周 且 !isDone       → "（结转，当前进度xx%）"
    · 逾期未触碰的历史项不纳入（避免陈旧数据干扰）
```

### 5.5 岗位模板引擎

**分类流程**：每条记录以 `类型 + 工作内容` 拼接文本，按模板类别正则**顺序匹配、首个命中即归类**，无命中归入末位"其他"类；空类别输出"无"保持模板编号完整。

| 岗位 | 模板类别（按匹配优先级） |
|---|---|
| 运维岗（10类） | 群/邮件支撑→沃工单→在线咨询→日报周报月报统计→日常巡检→监控告警→故障应急救援→数据处理/报表重跑→值班→其他事项 |
| 开发岗（4类） | 代码提交量→功能开发→bug修复或优化→其他临时安排任务 |
| 测试岗（4类） | 测试用例→测试bug数→测试文档报告输出→其他文档类 |
| 产品/项目管理岗（5类，特殊逻辑） | ①立项/验收/专利/软著/标书/一页纸→其他文档类 ②方案/材料/文档类**按完成态拆分**→已输出(完成)/输出中(未完成) ③项目跟进/协作/拆解 ④客户/业务对接 ⑤兜底 |

**下周计划段落自适应**：产品岗"本周已输出方案"在计划段自动改写为"下周计划输出方案"等措辞。

**岗位自动建议**：对本周完成项的工作类型多数投票（运维→运维岗；需求→开发岗；材料/验收/标书→产品岗），仅在用户未手动改过岗位时生效。

### 5.6 复制能力

`navigator.clipboard.writeText`（file://属安全上下文，点击手势满足要求）→ 失败降级 `document.execCommand('copy')`（隐藏textarea方案）→ 按钮反馈"✓ 已复制/复制失败"。

## 6. 部署与使用

### 6.1 环境要求

- 浏览器：Chrome/Edge等现代浏览器（无需安装任何依赖）
- 本地代理（仅在线获取需要）：macOS + Python 3（`xcode-select --install` 可装）

### 6.2 使用流程

```
离线模式：双击 周报整理助手.html → 选人员/岗位/周期 → 生成周报 → 一键复制

在线模式：双击 启动本地代理.command（保持窗口开启）
        → 打开 周报整理助手.html → 「在线获取最新数据」
        → 日志显示"本地代理已就绪"→ 自动拉取5个分表
        → 选人员 → 生成 → 一键复制

手动模式：打开腾讯文档 → 框选表格（含表头）复制 → 手动填写tab粘贴 → 解析
        → 选人员 → 生成 → 一键复制
```

### 6.3 常见问题

| 现象 | 原因与处理 |
|---|---|
| 在线获取日志全为"返回为空/超时" | 未启动本地代理（双击`.command`）或公共代理不可用；属预期降级，不影响快照使用 |
| 所选周无数据 | 文档数据更新滞后；点"跳转到最近有数据的一周" |
| 代理窗口误关闭 | 重新双击`.command`即可，页面无需刷新（下次获取自动探测） |
| 端口8790被占用 | `python3 本地数据代理.py 8891` 换端口，页面"本地数据代理"框同步修改 |

## 8. 已知限制与扩展方向

**限制**：
- 内置快照为静态数据（2026-10-10抓取），离线使用时反映的是抓取时点数据
- 公共CORS代理通道（L3）受腾讯接口Origin头拦截，长期不可用，仅作形式兜底
- 文档需保持"链接可读"权限；若收紧为登录可见，代理脚本需扩展登录Cookie头
- 单元格内含换行的粘贴解析按简单TSV处理（Excel复制场景内嵌换行会被引号包裹，已基本兼容）

**可扩展方向**：
- 代理支持 `--cookie` 参数注入登录态，应对文档权限收紧
- 快照刷新命令化：一键脚本重抓并回写HTML内嵌SNAPSHOT
- 输出模板配置化（当前4岗位模板硬编码于 `POS` 对象，可抽离为可编辑配置）
- 历史周报归档/导出（Markdown/图片）
